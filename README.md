# jevkit (PyPI)

Tooling for building on [TypeSafe](https://typesafe.ai)'s Jev, the first
System One model. Jev returns typed answers and calibrated probabilities instead
of generated text; jevkit is the ring of tools around that.

**Shipped:** jevkit-core, jevkit-lint, jevkit-pytest, jevkit-drift, jevkit-calibrate, jevkit-bench

See [the roadmap](docs/specs/roadmap.md) for what is planned, and
[the record format](docs/specs/record-format-v1.md) for the spine the testing,
drift, benchmark, and calibration packages share.

> Unofficial and unaffiliated with TypeSafe. Not an SDK: TypeSafe ships its own.
